# BETWEEN PARTY - 테이블 랜덤 배치 웹페이지

## 프로젝트 개요

솔로파티에서 사용할 테이블 랜덤 배치 웹사이트

## 기술 스택

- HTML
- CSS
- JavaScript (Vanilla)

## 입력 기능

### 기본 정보

- 남성 인원 수 입력
- 여성 인원 수 입력
- 테이블 개수 입력

### 그룹 입력

- 남성 그룹 추가 버튼
- 여성 그룹 추가 버튼
- 버튼 클릭 시 그룹 입력칸 추가
- 입력 예시: `1,3,5`
- 그룹 삭제 가능

## 배치 조건

- 남성과 여성은 각각 균등하게 테이블에 분배
- 예)
  - 남성 10명 / 여성 8명 / 테이블 3개
  - Table1 : 남4 / 여3
  - Table2 : 남3 / 여3
  - Table3 : 남3 / 여2

## 랜덤 배치 알고리즘

1.  테이블 생성
2.  테이블별 정원 계산
3.  그룹을 큰 순으로 정렬
4.  그룹을 랜덤한 테이블에 분산 배치
5.  Fisher-Yates Shuffle 사용
6.  남은 인원 랜덤 배치
7.  테이블 내부 번호 오름차순 정렬
8.  결과 출력

### 그룹 배치

- 그룹은 항상 같은 테이블
- 특정 테이블(1번)으로 고정되지 않음
- 배치 가능한 테이블 중 랜덤 선택
- 그룹이 한 테이블에 몰리지 않도록 최대한 분산

## 결과 출력

- 테이블별 카드 형태
- 남성과 여성 구분
- 번호는 오름차순

### 번호 스타일

- 번호만 출력
- 남성: 파란색 Glow
- 여성: 분홍색 Glow

## 테이블 레이아웃

- 1개 → 1열
- 2개 → 2열
- 3개 → 3열
- 4개 → 2 + 2
- 5개 → 3 + 2
- 6개 → 3 + 3
- 7개 → 4 + 3
- 마지막 행은 가운데 정렬
