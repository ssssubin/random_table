# BETWEEN PARTY - 테이블 랜덤 배치 웹페이지

## 프로젝트 개요

솔로파티에서 사용할 테이블 랜덤 배치 웹사이트

## 기술 스택

- HTML
- CSS
- JavaScript (Vanilla)

## 입력 기능

### 기본 정보

- 남성 인원 수 입력
- 여성 인원 수 입력
- 테이블 개수 입력
- 한 줄에 배치할 테이블 수 입력

### 그룹 입력

- 남성 그룹 추가 버튼
- 여성 그룹 추가 버튼
- 버튼 클릭 시 그룹 입력칸 추가
- 입력 예시: `1,3,5`
- 혼성 그룹 추가 버튼
  - 입력 예시: 
    - 남성 1,2번과 여성 6,7번 같이 앉히기 -> `1,2|6,7` 입력
- 그룹 삭제 가능

## 배치 조건

- 남성과 여성은 각각 균등하게 테이블에 분배
- 예)
  - 남성 10명 / 여성 8명 / 테이블 3개
  - Table1 : 남4 / 여3
  - Table2 : 남3 / 여3
  - Table3 : 남3 / 여2

## 랜덤 배치 알고리즘

1. 테이블 생성
   - 사용자 입력값에 따라 테이블 객체를 생성하고, 각 테이블마다 남성/여성 정원 정보를 초기화

2. 테이블별 정원 계산
   - 남성 인원 수와 여성 인원 수를 테이블 수로 나누어 기본 배분을 계산
   - 나머지는 테이블 순서대로 1명씩 추가해, 각 테이블의 남성/여성 최대 정원을 결정

3. 그룹을 크기 순으로 정렬
   - 단성 그룹과 혼성 그룹은 모두 크기가 큰 그룹부터 먼저 배치
   - 혼성 그룹은 남성/여성 인원 수의 합을 기준으로 정렬

4. 그룹을 분산 배치
   - 각 그룹은 배치 가능한 테이블 중에서, 해당 성별의 남은 정원과 현재 테이블의 배치 현황을 기준으로 가장 적게 채워진 테이블 후보를 찾음
   - 후보가 여러 개일 경우 그중 랜덤으로 하나를 선택해 배치
   - 이 과정으로 한 테이블에 그룹이 몰리지 않도록 분산

5. 남은 인원 채우기
   - 이미 배치된 그룹을 제외한 남은 사람들을 Fisher-Yates Shuffle로 섞은 뒤,
     각 테이블의 남은 정원에 맞춰 순차적으로 채움

6. 번호 정렬 및 결과 출력
   - 각 테이블의 남성 번호와 여성 번호를 오름차순으로 정렬한 뒤,
     카드 형태로 화면에 출력

### 그룹 배치 규칙

- 그룹은 항상 같은 테이블에 배치
- 특정 테이블(예: 1번 테이블)로 고정되지 않고 가능한 테이블 중에서 동적으로 선택
- 배치 가능한 테이블이 여러 개일 때는 현재 채워진 인원이 가장 적은 쪽을 우선하고, 동률이면 랜덤으로 선택
- 혼성 그룹도 남성/여성 각각의 정원 조건을 만족하는 테이블에 배치

## 결과 출력

- 테이블별 카드 형태
- 남성과 여성 구분
- 번호는 오름차순
- 테이블은 시계 방향으로 배치

### 번호 스타일

- 번호만 출력
- 남성: 파란색 Glow
- 여성: 분홍색 Glow
